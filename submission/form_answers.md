## 2. 提出作品の概要

**2-1. 取り組んだ課題の種類** → **自由課題**
**2-2. 作品名** ※Web公開・提出後変更不可 → **Tokyo Capital Bridge**

### 2-3. サービスの詳細（222字）

```
東京の資金を「海外投資家→上場企業→中小企業→都民」の四層に分けて可視化し、層と層がどれだけ連関しているかを255か月の月次データで実測するWebサービスです。そのうえで二つのツールを載せました。都民向けは、区市町村・年収・働き方を選ぶと使える制度と年間の節税額を円で出す「入口チェッカー」。事業者向けは、業種と規模から資金タイプを判定し、そのまま金融機関に出せる相談メモを生成する機能です。判定式と出典URLはすべて画面に全文表示しています。
```

### 2-4. 着目した課題・背景（195字）

```
東京は今年GFCIで世界10位に復帰し、東証プライムの売買代金の66.2%を海外投資家が占めます。一方、都が毎月景況を聞く中小企業3,875社の業況DIは255か月間ゼロを超えたことがありません。都民も一枚岩ではなく、住民1人あたりの住民税負担額は区市町村で7.9倍、23区内でも5.1倍の開きがあります。市場の活況が事業者にも家計にも届いていない。同じ東京で資金の回路が分断されています。
```

### 2-5. 課題・背景の解決方法（210字）

```
まず分断を数字で示しました。金利と業況DIは同月比較ではr=−0.03ですが、24か月ずらすとr=−0.54。金利は効いていないのではなく2年遅れて効いていました。資産形成の格差も、iDeCo等の利用率が所得とr=0.80で連動する一方、生命保険料控除は差が1.15倍。制度の使われ方の差として現れています。そこで、使っていない制度と失っている金額を円で示すツールと、事業者が窓口へ持参できる相談メモ生成を実装しました。
```

## 3. 技術詳細

### 3-1. 技術選定の理由（266字）

```
外部ライブラリを一切使わない単一HTMLで実装し、チャートはすべて手書きSVGです。理由は三つ。第一に、審査時にCDNやネットワークに依存せず確実に動くこと。第二に、Cloudflare Pagesへ置くだけで公開でき運用コストがゼロであること。第三に、ソースを開けば判定ロジックがそのまま読めることです。データ整形はPython、XLSXはSheetJS、PDFはpdf.jsで解析。構成比は合計が100%になることを検算し、連関は0〜24か月のラグを総当たりで走査しました。配色はカラーユニバーサルデザインを機械検証しています。
```

### 3-2. 生成AI等の活用方法（223字）

```
開発全体にClaude（Anthropic）を用いました。工夫したのは、AIに「作らせる」前に「疑わせる」ことです。景況調査の母集団に上場企業が含まれるかを検証させ、オーナー企業群だと判明して設計を変更しました。「金利と中小企業は無関係」という一度出た結論も、時差を入れて再計算させたらr=−0.54が出て覆りました。数値はすべて一次資料から機械抽出し検算を通しています。生成AIに判定文を書かせる実装は、誤りが見えなくなるため採用していません。
```
