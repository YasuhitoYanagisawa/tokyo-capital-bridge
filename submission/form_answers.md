## 2. 提出作品の概要

**2-1. 取り組んだ課題の種類** → **自由課題**

### 2-3. サービスの詳細（257字）

```
「東京資本橋」は、東京の資金を「海外投資家→上場企業→中小企業→都民」の四層に分けて可視化するWebサービスです。海外マネーのシェア、上場3市場の規模と利回り、中小企業3,875社の景況と調達金利、家計の余剰を同じ画面に並べ、さらに層と層がどれだけ連関しているかを月次データで実測します。国債10年利回りと都内中小企業の業況DIの相関はr=−0.03でした。事業者には資金タイプ判定と調達手段を、投資家には国債・株式・都債・CFの利回りとアクセス可否を返します。判定式と出典URLはすべて画面に全文表示しています。
```

### 2-4. 着目した課題・背景（262字）

```
東京は世界有数の金融市場です。東証プライムの売買代金の66.2%は海外投資家で、その75.3%が欧州経由。一方、都が毎月景況を聞く非上場の中小企業3,875社の業況DIは255か月間ゼロを超えたことがありません。両者を255か月そろえて相関をとるとr=−0.03。金利も株価も、中小企業の実感とはほぼ無関係でした。都民の家計には毎月212,929円の余剰がありますが、NISAで届くのは上場3,837社まで。円建ての個人向け都債は平成25年を最後に12年以上途絶えています。同じ東京で、資金の回路が層ごとに分断されています。
```

### 2-5. 課題・背景の解決方法（232字）

```
まず分断を数字で示し、次に動かせる場所を指します。①海外マネーは市場区分別シェアと地域別の出どころ、②上場企業は3市場の時価総額・回転率・配当利回りと債券市場、③中小企業は業況・調達金利・保証・倒産を可視化。④これらを毎月そろえ「今月のファイナンス環境」を前月差から機械的に判定します。⑤事業者には業種・規模・使途から資金タイプと調達手段を、⑥投資家には国債・株式・都債・CFの利回りとアクセス可否を並べ、閉じている入口（円建て都債、非上場への経路）を明示します。
```

## 3. 技術詳細

### 3-1. 技術選定の理由（282字）

```
外部ライブラリを一切使わない単一HTMLで実装し、チャートはすべて手書きSVGです。理由は三つ。第一に、審査時にCDNやネットワークに依存せず確実に動くこと。第二に、Cloudflare Pagesへ置くだけで公開でき運用コストがゼロであること。第三に、ソースを開けば判定ロジックがそのまま読めることです。データ整形はPython、景況XLSXとJPX統計はSheetJS、付帯調査PDFはpdf.jsで解析。構成比は各行の合計が100%になることを検算し、連関はピアソンの相関係数を255か月で計算しました。配色はカラーユニバーサルデザインを機械検証しています。
```

### 3-2. 生成AI等の活用方法（256字）

```
開発全体にClaude（Anthropic）を用いました。工夫したのは、AIに「作らせる」前に「疑わせる」ことです。当初は上場株式への投資マッチングを構想しましたが、景況調査の母集団に上場企業が含まれるかを検証させた結果、経営者年齢を設問に持つオーナー企業群だと判明し設計を変更。「金利と中小企業はつながっているはず」という前提も、255か月の相関を計算させたらr=−0.03で否定されました。数値はすべて一次資料から機械抽出し、構成比の検算を必ず通しています。AIの出力をそのまま信じない工程を組み込みました。
```
