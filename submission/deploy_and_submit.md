# デプロイと提出の手順

私の実行環境からは外部ネットワークに出られず（`curl` が全滅します）、
Cloudflare の認証情報もお預かりできないため、**この2つは私が代行できません。**
どちらも数分で終わる作業なので、手順を書きます。

---

## 1. Cloudflare Pages にデプロイする（約3分）

添付の **`deploy_cloudflare.zip`**（613KB）をそのまま使えます。
※ ハッカソン特典の Cloudflare アカウント（Paidプラン相当）でも、個人の無料アカウントでも同じ手順です。

1. https://dash.cloudflare.com/ にログイン
2. 左メニューの **Workers & Pages** → **Create** → **Pages** タブ → **Upload assets**
3. プロジェクト名に `tokyo-capital-bridge` と入力（URLは `tokyo-capital-bridge.pages.dev` になります）
4. **`deploy_cloudflare.zip` をドラッグ＆ドロップ**
   ※ zip をそのままドロップして構いません。展開してフォルダを入れる必要はありません
5. **Deploy site** を押す
6. 発行された URL を**シークレットウィンドウで開いて動作確認**

確認するのはこの3点です。

- トップが `index.html`（最新版 v4）で開くこと
- タブ 01〜09 が切り替わること
- 画面下の「ほかのバージョンを見る」から v1〜v4 に飛べること

### zip の中身

```
index.html        最新版（v4）  ← トップページ
versions.html     バージョン一覧
v1/ v2/ v3/ v4/   各バージョン
artifact.html     単体配布用
README.md         サービス説明・エンジン仕様・データ一覧
```
