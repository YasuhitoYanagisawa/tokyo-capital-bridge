# メンバー募集文（改訂案）

## A案：数字で殴る版（推奨・約300字）

```
【継ぐ東京】チーム募集中

東京都は毎月、都内の中小企業3,875社に景況を聞いています。そのDIは2005年から255か月間、一度も0を超えていません。同じ調査をよく読むと、経営者の34.1%が70歳以上、創業1980年以前が63.6%、2021年以降の創業はわずか0.6%。資金より先に、事業を引き継ぐ人が尽きかけていました。一方で都民の家計には毎月21万円の余りがある。それでもNISAは非上場のこの企業群に1円も届きません。

私たちは、この「金と人、二つの断絶」を都のオープンデータだけで可視化し、事業者・都民・支援機関を実在の窓口につなぐサービスを作ります。すでに動くプロトタイプがあります。

求めるメンバー：フロント／バックエンド開発、データ分析・可視化、UI/UXデザイン、中小企業金融・事業承継に詳しい方。
```

## B案：問いから入る版（約280字）

```
【継ぐ東京】チーム募集中

「都民の余剰資金を都内中小企業へ」——よく聞く話ですが、制度上ほとんど成立しないことをご存じですか。NISAもiDeCoも対象は上場株式等。都の景況調査に答えている3,875社は、経営者の34.1%が70歳以上、創業1980年以前が63.6%の非上場オーナー企業です。制度と実態が噛み合っていません。

私たちは、東京都のオープンデータだけを使って、①業種ごとにいま必要な資金の種類、②承継の緊急度、③都民の資金が実際に届く経路と届かない経路、を可視化するサービスを作っています。判定式は全文公開、ごまかしません。

求めるメンバー：フロント／バックエンド開発、データ分析・可視化、UI/UXデザイン、中小企業金融・事業承継に詳しい方。動くプロトタイプがあるので、続きから入れます。
```

求めるメンバー：フロント／バックエンド開発、データ分析・可視化、UI/UXデザイン、中小企業金融・事業承継に詳しい方。

## 元の募集文からの変更点と理由

| 元の記述 | 変更後 | 理由 |
|---|---|---|
| 「機関投資家のマネー」をつなぐ | 削除 | 調査対象は非上場のオーナー中小企業。機関投資家が入れる器がなく、実装できない |
| 「資産形成できていない都民」 | 「都民の家計には毎月21万円の余りがある。それでもNISAは1円も届かない」 | 実測値（212,929円）に置換。制度の断絶を主張に格上げ |
| 「都内スタートアップ・中小企業」 | 「創業1980年以前が63.6%」の中小企業 | Tokyo Startup Database は機械可読な形で公開されておらず、実データはスタートアップではなく老舗中小企業を示していた |
| 国際金融都市構想2.0／金融・資産運用特区との連動 | 削除 | 特区施策はプロ投資家・海外運用会社が対象で、この母集団に届かない。無理に接続すると審査で崩れる |
| 海外投資家向け英語対応 | 削除 | 非上場・オーナー経営・平均創業50年超の企業群に対する海外投資家導線は現実性が低い |
| ESG×成長投資 | 削除 | 裏づけとなる都のデータを確保できなかった |
| （新規） | 事業承継・M&A／実在の支援窓口への接続 | 経営者34.1%が70歳以上という一次データから直接導かれ、東京都の実施施策とも一致する |

**要点**：元の案は「政策キーワードに寄せる」構成でしたが、実データを当たると母集団が想定と違いました。キーワードを削って一次データの数字に置き換えたぶん、主張は狭くなりましたが、突かれても崩れません。
