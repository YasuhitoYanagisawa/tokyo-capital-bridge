# Tokyo Capital Bridge

東京の資金循環を四層で可視化し、都民の資産形成と成長企業の資金調達をつなぐ

**都知事杯オープンデータ・ハッカソン2026 応募作品**
公開URL： https://tokyo-capital-bridge.pages.dev/

---

## これは何か

東京の資金を **海外投資家 → 上場企業 → 中小企業 → 都民** の四層に分けて可視化し、
層と層がどれだけ連関しているかを **255か月の月次データ**で実測するWebサービスです。

そのうえで、読むだけで終わらせないための**ツールを2つ**載せています。

| 対象 | ツール | 何が出るか |
|---|---|---|
| 都民 | 資産形成の入口チェッカー | 区市町村・年収・働き方を選ぶと、使える制度と**年間の節税額を円で**表示 |
| 事業者 | 資金タイプ判定＋相談メモ生成 | 業種と規模から必要な資金タイプを判定し、**そのまま金融機関に出せる相談メモ**を生成 |

判定式・しきい値・出典URLは、すべて画面に全文表示しています。ブラックボックスはありません。

## 実測でわかったこと

### 1. 金利は効いていないのではなく、約2年遅れて効いていた

国債金利と中小企業の業況DIは、**同月で比べると r = −0.03**。ほぼ無関係に見えます。
そこで 0〜24か月のラグを総当たりで走査したところ ——

| 系列 | 最良ラグ | r | n |
|---|---|---|---|
| 国債2年・水準 | **24か月** | **−0.54** | 231 |
| 国債2年・前年差 | 0か月 | +0.49 | 243 |
| 国債10年・水準 | 24か月 | −0.40 | 231 |
| 国債10年・前年差 | 8か月 | +0.38 | 235 |

「効いていない」という一度出た結論が、時差を入れたら覆りました。
事業者にとっては、**いまの金利は2年後の業況の予告**として読めることになります。

### 2. 資産形成の格差は「制度の使われ方」に出ている

多摩・島しょ39市町村について、所得水準と所得控除の適用率を突き合わせました。

| 制度 | 所得との相関 | 利用率の開き |
|---|---|---|
| 生命保険料控除（守りの制度） | r = **−0.43** | 1.15倍 |
| iDeCo・小規模企業共済等（増やす制度） | r = **+0.80** | **2.52倍** |

守りの制度は誰でも使えているのに、**増やす制度だけが所得の高い地域に偏っています。**
同じ制度が同じ条件で用意されていても、実際に使われる度合いが違う。ここは情報の問題であり、
だからこそツールで介入できる余地があると考えました。

担税力そのものの格差は、全62区市町村で **7.9倍**（港区 582,777円 ↔ 檜原村 74,131円）、
**23区の中だけでも 5.1倍**あります。

### 3. 「円安だから儲かる」は、直近5年だけの話

日銀の USD/JPY 255か月から、12か月保有の窓を243本つくって検証しました。

| | |
|---|---|
| 円安になった窓 | 53.9% |
| **損益分岐（−2.68%）を下回った窓** | **33.7%** |
| 最悪の窓 | **−18.77%** |
| 直近5年に限れば円安の窓 | 90%（平均 +8.16%） |

3回に1回は負ける取引です。直近5年の体感は、20年の分布とは一致しません。

## 技術構成

- **単一HTML・外部ライブラリ0**。チャートはすべて手書きSVG
- ライト／ダーク両対応。ページ本体はどの幅でも横スクロールしない（360px幅まで実測）
- 日本語の折り返しは `word-break:auto-phrase`（文節区切り）＋ `line-break:strict`（禁則）＋ `text-wrap:pretty`
- 狭い画面で縮小すると軸ラベルが読めなくなる図だけ、原寸のまま図の中で横スクロールさせる（最小9px保証）
- 配色はカラーユニバーサルデザイン（P型・T型色覚）を機械検証済み。色のみに意味を持たせない
- XLSXは SheetJS、PDFは pdf.js で解析 → Python で整形・検算 → 静的JSONとしてバンドル
- 構成比は各行の合計が100%になることを検算のうえ採録
- Playwright（`verify.js`）でヘッドレス検証、`deck/build.js` でプレゼン資料PDFを生成

## ビルド

```bash
python3 build_data.py    # 一次データ → data/tcb_data.js
python3 make_v4.py       # 部品 → src/v4_capital-bridge.html
python3 build.py         # → dist/
node verify.js           # ヘッドレス検証
```

`dist/` をそのまま静的ホスティングに置けば動きます。ビルド手順は不要です。

## ディレクトリ

```
verify.js         Playwrightによるヘッドレス検証

```

## 利用データ

東京都オープンデータ（CC BY 4.0）を中心に、財務省・日本銀行・JPX・米国財務省の公表統計を加えた
**17件**を使用しています。全件の取得元URLは画面「09 データと判定ロジック」に掲載しています。

主なもの：

- 東京都中小企業の景況（月次・3,875社・255か月／東京都産業労働局）
- 東京都統計年鑑 令和5年 15金融・14家計・21財政（東京都総務局）
- 市町村税課税状況等の調 令和5年度（東京都総務局）
- 東京都財務局 都債IR情報
- 東京信用保証協会 事業概況（代位弁済を2024年度まで延長）
- 財務省 国債金利情報／日本銀行 為替相場／JPX 投資部門別売買状況
