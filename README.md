## 1. これは何か（30秒版）

東京都は毎月、都内の中小企業3,875社に「景況はどうか」を聞いている。
その回答は2005年5月から255か月ぶん、オープンデータとして公開されている。
**そのDI（業況判断指数）は、20年間ただの一度も0を超えていない。**

一方で――

- 都内勤労者世帯は毎月 **212,929円** の黒字を出しながら、その多くを現預金に置いている（統計年鑑 14-2）
- 都内銀行の預貸率は 76.9% → **72.3%** へ低下。預金は増えるが貸出は増えない（15-1）
- 代位弁済（保証協会による肩代わり返済）は2021年度2,724件 → 2023年度 **6,179件** と2.3倍（15-3）

**金は余っている。足りないのは「どこに、どんな形で出すか」の解像度。**

東京資本橋は、都の景況データを業種ごとに分解して
「いま必要なのは、防衛的運転資金か／価格転嫁対応か／攻めの成長資金か」を
ルールベースで判定し、**投資家・事業者・都民の三者に同じ一次データを見せる**。

## 2. 判定エンジン（ブラックボックスなし）

各業種について、直近3か月の実データから5つの指標を計算する。

| 記号 | 定義 | 用いる系列 |
|---|---|---|
| L | 直近3か月の業況DI平均 | 業況（当月） |
| M | L − 前年同期3か月平均（モメンタム） | 業況（当月） |
| P | 販売単価DI − 仕入単価DI（価格転嫁ギャップ） | 販売単価・仕入単価（前月比） |
| E | 見通しDI3か月平均 − L（期待ギャップ） | 業況見通し（今後3か月） |
| S | 直近3か月の売上高DI平均 | 売上高（前年同月比） |

判定は上から順に評価：

1. **防衛的運転資金・事業再構築** … `L < -34`、または `L < -28 かつ M < 0`
2. **攻めの成長資金（エクイティ適性）** … `M > +6 かつ E > 0 かつ L > -32`
3. **価格転嫁・コスト対応資金** … `P < -15`
4. **安定・設備投資資金** … `L > -14 かつ S > -14`
5. **中立（様子見）** … 上記のいずれにも該当しない

投資妙味スコア `= 50 + 0.62 × ( 2.2·M + 1.4·E + 0.5·(L+25) + 0.6·S + 0.5·P )`（2〜98に丸め）

すべてのしきい値と加重は画面上に全文表示しており、生データから誰でも再計算できる。

## 3. 三つの視点

| 視点 | 見えるもの |
|---|---|
| **02 投資家** | 20年 × 24業種の業況ヒートマップ、業種別DI時系列（4指標）、投資妙味スコアランキング、業種別倒産件数との突き合わせ |

| **04 都民** | 都内勤労者世帯の実測黒字を起点にした積立シミュレーター。その資金が向かう先のスコア上位業種 |

## 5. 技術構成

- **単一HTML / 外部ライブラリ0**。チャートはすべて手書きSVG（D3等も不使用）
- 景況XLSXは SheetJS で解析 → Python で整形 → 静的JSONとしてバンドル
- ライト／ダーク両対応、モバイル対応、横スクロールなし
- 配色はカラーユニバーサルデザイン検証済み（P型・T型色覚での色差ΔE基準をクリア）。色のみに意味を持たせず、全系列に直接ラベルと数表ビューを用意

## 6. デプロイ（Cloudflare Pages）

`index.html` 1枚だけの静的サイトなので、ビルド不要。

### 方法A：ダッシュボードから（最短）

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Pages** → **Upload assets**
2. プロジェクト名を入力（例：`tokyo-capital-bridge`）
3. このフォルダをドラッグ＆ドロップ → **Deploy**
4. `https://tokyo-capital-bridge.pages.dev` が発行される → 提出フォームのデモURL欄へ

### 方法B：CLI から

```bash
npx wrangler pages deploy . --project-name=tokyo-capital-bridge
```

（`README.md` を配信したくない場合は `index.html` だけを別フォルダに置いてデプロイ）
